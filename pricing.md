# Revdoku pricing

Canonical browser page: https://app.revdoku.com/pricing

Prices are USD. New accounts start on Free. No credit card is required.

| Limit | Anonymous | Free | Personal | Developer |
| --- | ---: | ---: | ---: | ---: |
| Price | $0 | $0 | $3.99/month | $19.99/month |
| Account needed | No | Yes | Yes | Yes |
| Storage | — | 5 GB | 50 GB | 250 GB |
| Published websites | 1 preview | 100 | 500 | 2,000 |
| Maximum website size | 25 MB | 1 GB | 5 GB | 20 GB |
| Maximum normal file | 25 MB | 100 MB | 250 MB | 500 MB |
| Website lifetime | 24 hours | Permanent | Permanent | Permanent |
| Versions per file | 1 | 10 | 50 | 200 |
| Publish rate | 60/hour/IP | 60/hour | 200/hour | 200/hour |
| Forms submissions | None | 3/day | 100/day | 500/day |
| Analytics | None | None | Included | Included |
| Website custom domains | None | 1 | 5 | 20 |
| Brand domains | None | None | None | 1 |
| Website Name | Randomized | Randomized | Customizable | Customizable |
| Website access | Public | Public | Public, Password, Require Email | Public, Password, Require Email |
Anonymous previews are public-only and never create a private bucket. They do not include forms, analytics, custom domains, or a custom URL.

Free and anonymous websites use a randomized `<word>-<word>-<4 digits>.revdoku.site` URL. Choosing or renaming the Website Name requires Personal or Developer.

Storage is shared by current files and retained file versions. Revdoku does not impose a visitor or transfer quota on these plans.
