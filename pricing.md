# Revdoku pricing

Canonical browser page: https://app.revdoku.com/pricing

Prices are USD. New accounts start on Free. No credit card is required.

| Limit | Anonymous | Free | Hobby | Developer |
| --- | ---: | ---: | ---: | ---: |
| Price | $0 | $0 | $3.99/month | $19.99/month |
| Account needed | No | Yes | Yes | Yes |
| Storage | — | 10 GB | 500 GB | 2 TB |
| Published websites | 1 preview | 500 | 1,000 | Unlimited |
| Unpublished private buckets | 0 | 1 | 5 | 10 |
| Maximum website size | 25 MB | 10 GB | 500 GB | 2 TB |
| Maximum normal file | 25 MB | 100 MB | 250 MB | 500 MB |
| Maximum PDF file | 25 MB | 0.5 MB | 250 MB | 500 MB |
| Website lifetime | 24 hours | Permanent | Permanent | Permanent |
| Versions per file | 1 | 10 | 50 | 200 |

| Analytics | None | Basic totals | Included | Included |
| Website custom domains | None | 1 | 5 | 20 |
| Brand domains | None | None | None | 1 |
| Revdoku URL | Randomized | Randomized | Customizable | Customizable |
| Website access | Public | Public | Public, Password, Require Email | Public, Password, Require Email |
| Search indexing default | Noindex | Noindex | Indexable | Indexable |
| Referrer policy | `no-referrer` | `strict-origin-when-cross-origin` | `strict-origin-when-cross-origin` | `strict-origin-when-cross-origin` |
| Site-wide Revdoku footer or badge | None | None | None | None |

Anonymous previews are public-only and never create a private bucket. They do not include forms, analytics, custom domains, or a custom URL. Updating an anonymous preview does not extend its original 24-hour expiry.

Free and anonymous websites use a randomized `<word>-<word>-<4 digits>.revdoku.site` URL. Choosing or renaming a Revdoku URL requires Hobby or Developer.

Storage is shared by current files and retained file versions. Revdoku does not impose a visitor or transfer quota on these plans.

Hosted forms retain a small clickable Revdoku credit. Revdoku does not add a site-wide promotional footer or badge.

Account creation is browser-only: https://app.revdoku.com/users/sign_up
