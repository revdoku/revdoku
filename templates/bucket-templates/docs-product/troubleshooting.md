## I cannot sign in

1. Make sure that the email address is correct.
2. Request a new sign-in link. A link works one time.
3. Look in your spam folder.

## An import skips rows

| Message | Cause | What to do |
| --- | --- | --- |
| Missing name | The `name` column is empty | Enter a name in each row |
| Invalid price | The price is not a number | Use digits and a point, such as `24.90` |
| Too many rows | The file has more than 10,000 rows | Divide the file |

## The app shows old data

Reload the page. In the mobile app, pull down to refresh.

## Still not working?

Use **Ask** on this site and leave a message. Include what you did and what you saw.
