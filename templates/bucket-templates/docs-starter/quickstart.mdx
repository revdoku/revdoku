---
title: Quickstart
description: Make your first request.
---

<Steps>
  <Step title="Get an API key">
    Create a key in your account settings. Keep it secret.
  </Step>
  <Step title="Send a request">
    List the plants in your store.

    <CodeGroup>
    ```bash cURL
    curl https://api.example.com/v1/plants \
      -H "Authorization: Bearer $ACME_API_KEY"
    ```

    ```javascript Node.js
    const response = await fetch("https://api.example.com/v1/plants", {
      headers: { Authorization: `Bearer ${process.env.ACME_API_KEY}` },
    });
    console.log(await response.json());
    ```
    </CodeGroup>
  </Step>
  <Step title="Try it in the browser">
    Open the [API console](/api-reference/console/) or the [API tester](/examples/api-tester/).
  </Step>
</Steps>
