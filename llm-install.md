# Revdoku agent setup

Canonical instructions: [llms-install.md](./llms-install.md).

```text
Connect Revdoku so you can store and share my files, and read incoming email and attachments in private buckets.

Follow https://revdoku.com/llms-install.md. If you have shell and filesystem access, install and use the local CLI. Otherwise, connect through hosted MCP.

Complete sign-in in the browser, check the connection, and ask what I want to do with my files or incoming email.
```

Account creation happens at `https://app.revdoku.com/users/sign_up`. Revdoku
requires authentication before an agent stores files or reads incoming email.
